### Запуск проекта

1. Установить зависимости
```
npm install
```

2. Запустить сервер разработки
```
npm run dev
```

3. Открыть приложение в браузере по адресу:

```
http://localhost:5173
```

### Краткое описание работы таймера активности

Каждые 2 секунды каждый питомец тратит одну единицу энергии

- Если энергии меньше 5, то при каждом обновление его настроение становится средним (1 из 2)

- Если энергии меньше 2, то при каждом обновление его настроение становится плохим (0 из 2)
